# GitInsight - Personal Analytics Dashboard

A comprehensive personal analytics dashboard that tracks your GitHub activity, commit history, and coding patterns. Visualize your development journey with interactive charts, streak tracking, and branch visualization.

## Project Overview

GitInsight transforms your GitHub data into meaningful insights through an intuitive dashboard. Track your coding habits, analyze commit patterns, visualize branch structures, and maintain coding streaks - all in one place.

### Why GitInsight?

- **Data-Driven Development**: Understand your coding patterns and productivity trends
- **Visual Branch History**: Interactive visualization of your repository's branch structure
- **Streak Tracking**: Gamify your coding journey with commit streak monitoring
- **Personal Insights**: Gain actionable insights into your development workflow

## Features

- **Interactive Dashboard**: Real-time analytics of your GitHub activity
- **Streak Tracking**: Monitor and maintain your coding streaks
- **Branch Visualization**: Visual representation of repository branching patterns
- **Commit Analytics**: Detailed analysis of commit frequency and patterns
- **Beautiful Charts**: Powered by Chart.js for stunning data visualization
- **Responsive Design**: Works seamlessly across all devices

## Tech Stack

### Frontend
- **React** - UI framework for building interactive components
- **Vite** - Fast build tool and development server
- **Chart.js** - Data visualization library

### Backend
- **Node.js** - Server-side JavaScript runtime
- **SQLite** - Lightweight database for data storage

### Deployment
- **Frontend**: Vercel/Netlify
- **Backend**: Railway/Heroku

## Getting Started

### Prerequisites
- Node.js (v16 or higher)
- npm or yarn
- Git

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/GitInsight.git
   cd GitInsight
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Set up environment variables**
   ```bash
   cp .env.example .env
   # Add your GitHub API token and other configuration
   ```

4. **Start development server**
   ```bash
   npm run dev
   ```

5. **Open your browser**
   Navigate to `http://localhost:5173`

## Usage

1. **Connect your GitHub account** - Authenticate with GitHub to access your repositories
2. **Select repositories** - Choose which repositories to track
3. **View analytics** - Explore your coding patterns through interactive dashboards
4. **Track streaks** - Monitor your daily coding activity
5. **Visualize branches** - Understand your project's branching strategy
